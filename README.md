# backend-development-workspace

Keegan Ringnalda

## Purpose

This is the workspace for the Application Development course taken via Rize

## Overview

This repository is my digital notebook for the Application Development course. It
holds the projects I build, the things I learn, and the reference materials I
collect along the way. Each unit of the course gets its own folder so coursework
stays organized and easy to find.

## Learning Objectives

- Master Git and version control workflows
- Write clean, maintainable backend scripts
- Apply advanced scripting patterns and error handling
- Design and implement RESTful APIs
- Communicate technical work clearly through documentation

## How I Plan to Use This Repository

- **Track projects:** each unit folder will hold the projects I complete for that
  section of the course
- **Keep a learning log:** `learning-log.md` will grow throughout the semester as I
  record goals, lessons learned, and wins
- **Collect references:** `resources.md` will build into a curated list of useful
  backend development links
- **Build a cheat sheet:** `git-reference.md` will become my personal Git command
  reference as I encounter new commands
